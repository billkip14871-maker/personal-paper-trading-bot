# Personal Paper Trading Bot

A modern paper-trading bot for testing automated trading strategies using virtual money.

## Features

- Trading dashboard
- Virtual account balance
- Profit and loss tracking
- Market price charts
- RSI, MACD and moving-average indicators
- Automated trading signals
- Paper trading engine
- Stop-loss and take-profit simulation
- Backtesting
- Trade history
- Portfolio performance
- Risk management
- Start/stop bot controls
- Mobile-friendly interface
- Dark trading dashboard

## Safety

This project is initially **PAPER TRADING ONLY**.

It does not place real-money trades.

Never commit API keys, passwords, tokens, or other secrets to this repository.

## Planned Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- Server-side API routes
- Market-data API
- Paper-trading engine
- Backtesting engine
